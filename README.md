# 💼 Big Spender: Volatility Cycle

A tense, polished, and addictive dark cyber-finance incremental/idle game built entirely inside a single-file web interface. Balance massive wealth generation against the constant threat of regulatory enforcement arrays.

---

## 🕹️ Core Gameplay Mechanics

*   **Central Funding Matrix:** Inject raw capital manually by clicking the Central Hub. Each click spikes localized heat networks.
*   **Asset Infrastructure:** Acquire up to 10 unique automated business vectors, varying from street-level fronts to quantum orbital networks.
*   **Volatility Arrays:** Fronts are categorized by risk profiles:
    *   *Standard:* Steady income, low suspicion.
    *   *High-Heat:* Explosive, volatile revenues that rapidly push the heat index toward a system breakdown.
    *   *Stealth:* Low-yield, high-encryption firms that slow down visibility spikes.
*   **Mothball Operations:** When the Heat Index hits WARNING or CRITICAL levels, you can instantly shut down operations to freeze revenue and rapidly disperse suspicion before a systemic RAID occurs.
*   **Launder Reputation (Prestige):** Purge your operational grid and swap identities to claim permanent **Reputation Points**, granting a compounding $+2\%$ global revenue boost per point on your next run.

---

## 🛠️ Architecture & Tech Stack

This project is optimized for rapid deployment and features a modular, zero-dependency codebase:

*   **Frontend Shell:** Responsive HTML5 optimized for modern desktop and mobile browsers.
*   **Styling Engine:** Tailwind CSS via CDN paired with JetBrains Mono typography for a terminal-deck aesthetic.
*   **State & Simulation Engine:** Native JavaScript tracking real-time compounding income calculus, offline simulation, and localized storage.
*   **Persistence Layer:** Automated browser `localStorage` engine with manual string import/export diagnostics.

---

## 🚀 Getting Started / Local Deployment

Because the entire game engine is consolidated, it requires absolutely no compilation, build tools, or web server to play.

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
3. Start leveraging capital.
